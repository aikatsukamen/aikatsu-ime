# インストールと有効化・無効化

## Google 日本語入力 / Mozc

### インストール

1. IMEアイコンを右クリック →「辞書ツール」を開く
2. 「管理」→「新規辞書にインポート」
3. `google/aikatsu-names.txt` を選び、辞書名を `アイカツ` などにする

### 有効化・無効化

辞書ツールの左側の辞書一覧で、辞書名の左のチェックボックスを外すだけです。
再変換は即座に反映されます。**執筆時だけONにする用途に最も向いています。**

## Microsoft IME

### インストール

1. IMEアイコンを右クリック →「単語の追加」→「ユーザー辞書ツール」
2. 「ツール」→「テキストファイルからの登録」
3. `msime/aikatsu-names.txt` を選ぶ

ファイルは UTF-16LE (BOM付き) / CRLF で出力しています。文字化けする場合はこのエンコーディングのまま渡せているか確認してください。

> **Windows 11 の新しい Microsoft IME で一括登録に失敗する場合**
> 「設定 → 時刻と言語 → 言語と地域 → 日本語 → 言語のオプション → Microsoft IME → 全般」で
> 「以前のバージョンの Microsoft IME を使う」をオンにしてから再試行してください。

### 有効化・無効化

辞書単位のチェックボックスによるON/OFFはありません。実質的な手段は次の2つです。

- **ユーザー辞書ファイルを分ける**: アイカツ辞書専用の `.dic` を作り、「Microsoft IME の詳細設定 → 辞書/学習」で使用するユーザー辞書を切り替える。切り替えには設定画面を開く必要があります
- **不要になったら削除する**: 辞書ツールで対象語を選択して削除

手軽な切り替えを重視するなら、よみに接頭辞の付いた `full-prefixed` を入れっぱなしにする方が現実的です。

## ATOK

### インストール

1. 「ATOK 辞書ユーティリティ」を起動
2. 「一括処理」→「単語一括登録」
3. `atok/aikatsu-names.txt`（Shift_JIS版）を選ぶ
   - 読み込みに失敗する場合は `atok/aikatsu-names-utf8.txt` を試す

登録先はユーザー辞書ではなく、新規に作った辞書ファイルにしておくと後の管理が楽です。

### 有効化・無効化

「ATOK 辞書セットの設定」で、アイカツ辞書を含む辞書セットと含まない辞書セットを作っておけば、
変換モードの切り替えだけで実質的にON/OFFできます。ATOKはこの辞書セット機能が強力です。

## macOS ユーザ辞書

### インストール

1. 「システム設定」→「キーボード」→「入力ソース」→「編集」→「ユーザ辞書」
2. `macos/aikatsu-names.plist` をリストの上にドラッグ＆ドロップ

### 有効化・無効化

**辞書単位のON/OFF機能はありません。** 入れたら常に有効です。

日常の変換を汚したくない場合は `macos/aikatsu-full-prefixed.plist` を使ってください。
`あかほしみやいちご` のようによみの先頭に `あか` が付くため、通常の変換には一切干渉しません。

一括削除したい場合は、ユーザ辞書の一覧でアイカツ辞書のエントリを範囲選択して `-` ボタンで消せます。
iCloud で同期している場合、他のデバイスにも反映されます。
